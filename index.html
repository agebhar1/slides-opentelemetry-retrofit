OpenTelemetry

What is OpenTelemetry?

  • Open Source
  • vendor/tool-agnostic

Main Components

  • Specification API, SDK, Data1.60.0
  • Protocol (OTLP)1.11.0
  • Semantic Conventions1.44.0
  • API & SDKs
  • Library Ecosystem
  • Collector

Context Propagation

  • correlate signals with each other

Signals

  • Traces path of a request
  • Metrics measurement captured at runtime
  • Logs recording of an event
  • Baggage contextual information passed between signals

Traces

  • set of events across various components
  • implicitly defined by spans
  • trace ≈ direct acyclic graph of spans
  • requires concept of context propagation

Spans

  • operation name
  • start/finish timestamp
  • Attributes (0..*)
  • events (0..*)
  • parent's Span identifier (0..1)
  • Links to causally-related spans (0..*)
  • SpanContext
SpanContext
  • Trace ID (worldwide unique, group all spans for specific trace)
  • Span ID (globally unique)
  • Trace Flags (options for a trace)
  • Tracestate (k/v pairs; vendor specific; see W3C Trace Context)

Baggage

  • k/v store
  • propagated alongside context
    → available across service boundaries
  • ⚠ consider security (exposure/tampering)
  • ≠ span/metrics/logs attributes
